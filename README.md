# 🎓 Student Dropout & Success Prediction Dataset

Welcome to the **Student Dropout & Success Prediction Dataset** repository! This dataset helps analyze factors influencing student retention, academic success, and dropout risks using machine learning and statistical models.

## 📌 Dataset Overview
- 📊 **Student Demographics:** Age, gender, socioeconomic background  
- 📚 **Academic Performance:** GPA, attendance, and extracurricular involvement  
- 🏫 **Institutional Factors:** School type, funding, and educational resources  
- 🔍 **Dropout Indicators:** Patterns leading to disengagement and academic failure  

## 📂 Data Format
The dataset is structured in CSV format with key attributes:
- `Student ID` – Unique identifier for each student  
- `Age` – Student’s age at enrollment  
- `Gender` – Male, Female, or Other  
- `Socioeconomic Status` – Household income and parental education level  
- `GPA` – Academic performance indicator  
- `Attendance (%)` – Percentage of days attended  
- `Extracurricular Participation` – Involvement in school activities  
- `Dropout Risk Level` – Prediction of student disengagement
